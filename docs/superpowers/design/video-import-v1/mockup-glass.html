跟读库 · 玻璃质感与动效(设计稿 v2)

在 v1 的 9 个画面基础上,换上「透明玻璃」外观,并从 reactbits.dev 的组件库里挑了 12 个适合手机端的效果,用纯 CSS / 少量 JS 复刻出来给你看(正式实现时是自写的小组件,不会引入 reactbits 的依赖:它的组件多为 React + GSAP / three.js,体积大,而我们主包有预算)。下面 5 个画面都是可操作的:卡片上按住、点「加入练习」、拖速度滑块、点「重播」,可以直接看到效果。

选中的 12 个组件

reactbits 组件用在哪怎么落地成本 / 风险
GlassSurface(Components)顶栏、底部标签、底部弹层、控制条、评分卡半透明填充 + 模糊 + 饱和 + 内高光边 + 阴影,统一成一个 .glass 类模糊要 GPU;一屏最多 3 层(项目既有规则);低端机自动降为实色(已有 .lite 机制)
SoftAurora(Backgrounds)页面背景,玻璃需要"后面有东西"才好看3 团模糊色块缓慢漂移,纯 CSS;不用 WebGL 版很低;省电模式 / 减少动态时静止
SpotlightCard列表卡片、按钮按住 / 悬停时高光跟随手指,pointermove 写两个 CSS 变量极低
SpecularButton主按钮「开始导入 / 添加」渐变底 + 内高光 + 斜向光带周期性扫过极低(一个伪元素动画)
ShinyText(Text)「识别中…生成句子」状态文字background-clip:text + 流光渐变极低;仅处理中的卡片使用
Stepper处理阶段:探测 → 取回 → 转码 → 字幕 → 转写 → 分句圆点 + 连线,当前阶段脉冲极低
BorderGlow / ElectricBorder当前播放的句子conic-gradient 旋转描边(只描 1.5px)低;每屏仅一句在动
GradualBlur(Animations)句子列表底部,文字滑入控制条时渐进模糊一层带遮罩的 backdrop-filter算一层模糊(播放器 3 层:顶栏、渐进模糊、控制条)
ElasticSlider播放速度 0.5–1.25拖动有弹性,吸附到 4 个档位低;替代原来的 4 个小按钮
CountUp(Text)+ GradientText评分数字、配额数字数字从 0 滚到目标;分数高时渐变色字极低
ClickSpark点「加入练习」星标、拿到高分时点击处迸出 8 颗小火花极低;一次性
BlurTextAI 分析逐词浮现每个词从模糊到清晰,依次延迟低;只在生成完成的那一次

没选的:FluidGlass、Lanyard、ModelViewer、Galaxy、LiquidEther 等(WebGL / three.js,几百 KB,耗电,手机端收益小);Dock、各类 Menu / Gallery(桌面交互)。所有动效遵守:系统开了「减少动态效果」时全部静止;低端机走降级(去模糊、去动画);单屏模糊层 ≤ 3;主包新增体积目标 ≤ 2 kB gzip(都在跟读库的懒加载块里,只有 .glass 与 .aurora 两个公共样式进主包)。
