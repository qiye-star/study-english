Liquid glass · 整体视觉稿 v2

v2 相对 v1:① 规则 4 成为硬规则:模糊层上只放标题(≥ 17px 半粗)和图标;任何句子、提示、标签、按钮文字都放在托板(凹井,固定 ≥ 90% 实底,不随透明度滑块变)上 —— 输入条提示、「按住 说话」、弹层 / 对话框内容、DOCK 次要按钮;提示(toast)与公告横幅干脆不模糊。② 对话列表「新对话」改为不模糊的悬浮面板。③ 新增:单词复习选择题(答后)、组件样张、对话框 + 提示、底部弹层。v1 保持不变(../liquid-glass-v1/)。

克制的瓷白 / 石墨液态玻璃:近单色、大圆角、低对比的材质,唯一强调色是钴蓝(Rev 3 已定)。三级深度 E0 底(页面背景)→ E1 分区(每块内容一块悬浮玻璃,不模糊)→ E2 悬浮(标题胶囊、输入条、浮动按钮、弹层、底栏,模糊)。所有玻璃参数和页面背景色都是 CSS 变量,由「我的 › 外观与主题」实时驱动:手机里那一页和右侧「主题面板」是同一份状态,拖任何一个,整页的组件和手机一起变。数值见提案 2026-10-15-liquid-glass-overall-design-proposal.md §3 / §4 / §6 与 Rev 3;偏差见 picks.md。

D · 对比度(随主题面板实时计算)

WCAG 2.x 相对亮度。E0 = 正文直接在背景上(只有大标题与副标题);E1 分区不模糊,按背景最不利的一端合成;E2 / T3 会模糊任何内容,按最坏情况合成(浅色模式背后纯黑,深色模式背后纯白),真实情况因模糊平均更好。地板来自提案 §6.1(T1 .50 / .04,T2 .55 / .50,顶栏 .62 / .58,T3 .62 / .58,模糊 < 8px 时地板 +.20,低端机 .80)。E2 / T3 玻璃本身在严格最坏情况下撑不住次要文字(表中 ✗),所以 v2 规则 4:玻璃上只放 17px 半粗标题(按提案 §2.6 要求 ≥ 3:1)与图标,其余文字都在「托板」上,托板一行在任何背景下都 ≥ 4.5。
