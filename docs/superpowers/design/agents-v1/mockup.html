设计要点(请确认)

  • 过程胶囊:回复生成时自动展开,结束后折叠成一行;点开看「上下文 → 工具 → 思路」。默认折叠,避免把对话变成日志。

  • 工具失败不阻断回复:显示红色失败行和「重试」,回复里说明哪项没用上。
