#决定(设计稿的做法)备选
1分段文案「我的 / 精选」与底栏「我的」(个人页)同名。设计稿按计划写「我的」。改成「我的素材 / 精选」或「我的库 / 精选」,避免两个「我的」。
2390 宽是 1 列大卡(计划:≥ 400px 才 2 列),一屏约 2 张。窄屏改成「我的」那样的横向紧凑卡(左侧 96×54 封面),一屏 5–6 张;或把 2 列门槛降到 360px(标题更容易被截断)。
3级别徽标用淡蓝,标签用中性芯片;副本的「精选」徽标用中性玻璃 + 蓝色小星(不用琥珀)。级别按 A / B / C 分三色(会占用绿 / 琥珀已有的「分数」含义,不推荐)。
4许可说明用 ink-2 11px、80% 不透明(计划写 text-ink-3,但 theme.css 规定 ink-3 不用于文字)。按计划用 ink-3。
5添加时遇到「已下架」(404):吐司 + 按钮恢复,卡片留在列表里直到下次刷新。同时把这张卡从列表移除(推荐,避免用户再点一次又失败;实现很小)。
6删除副本:现有正文 + 一行补充(R-W5)。现有第一句「媒体文件和句子会被删除」对副本不准确。副本换一整段专用正文(要多 1 个文案键,总数仍 ≤ 15)。
7副本卡片不显示 ⋯(菜单里两项都被去掉);计划 R-W5 提到的「改标题」在现有 ⋯ 菜单里并不存在。保留 ⋯ 并显示一条灰色说明「精选素材不能重新识别或换字幕」。
8有封面的音频条目,播放页舞台从 3:1 改为 16:9:3:1 只有约 130px 高,扣掉状态栏与顶栏胶囊后封面只露出一条;代价是句子区少约 90px。保持 3:1(封面只是一条氛围色带);或折中 2:1。
9「精选」页签隐藏已用空间条与「添加素材」按钮(计划如此);离线只用现有错误卡 + 重试,不加离线横幅。—
