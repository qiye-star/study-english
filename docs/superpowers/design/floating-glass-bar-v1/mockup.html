#决定本稿的取值
D1改哪里只改全站底部 Tab 栏的形状与玻璃。对话输入条、复习 / 学新词 / 拼写 / 排位的 DOCK 操作条、通话控制台、弹层底部按钮条样式不变,只跟着上移。若 owner 指的是别的「下面部分」(例如跟读库播放器的控制胶囊),请指出。
D2几何左右 12px、圆角 28px(与通话控制台同一圆角令牌 rounded-dock)、高 64px(内边距 4px + 56px 标签行)、下沿 = max(10px, 安全区 − 8px)(iPhone 上约 26px,横条之上;无安全区的手机 10px)、平板最宽 640px 居中。
D3透明度A 6% / B 10% / C 16% 三选一(白色底色 / 深色模式用 surface 色)。推荐 B:A 在深色海报上标签开始发虚,C 已经像「磨砂」不像「透明」。模糊 28px、饱和 1.8(现在是 20px / 1.8)。底色永远不为 0。
D4可读性规则透明之后标签对比度不再由底色保证,改由文字光晕保证:标签与图标加一圈浅色(深色模式为深色)光晕;当前标签保留蓝色小胶囊底(浅 14% / 深 20%)。可以用「文字光晕」开关看去掉后的样子(不推荐)。
D5描边与阴影1px 白色高光描边 + 顶部内高光 + 柔和外阴影;去掉原来顶部那条发丝线。
D6回退不支持模糊:94% 实心;「减少透明度」:实心 surface + 发丝线描边(仍是圆角胶囊);低端机:模糊 12px + 62% 底色。三种情况形状都不变。
D7操作条与胶囊的间距DOCK、输入条下沿离胶囊上沿 8px;中间这 8px 与胶囊两侧会透出滚动内容(见复习页)。备选:操作条也改成悬浮圆角(不在本轮,另开)。
D8跟读库渐进模糊列表底部的渐进模糊层仍贴在「底栏占位」上沿(现在会停在胶囊上方 8px)。备选:让它延伸到屏幕底部(会和胶囊叠两层模糊,超出每屏 3 层的上限,不推荐)。

本稿只证明「看起来怎样」。真机上的模糊质量、iOS 主屏模式下的安全区位置、低端安卓的滚动流畅度、深色海报上标签的实际可读性都未验证,见计划的真机清单。
