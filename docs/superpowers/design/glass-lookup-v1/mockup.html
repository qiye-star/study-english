#决定本稿的取值
D1哪里能长按查词所有标记为「可查词」的英文内容(计划里的清单,约 40 处,含学新词 / 复习 / 已学 / 拼写 / 对话 / 跟读库 / 生词本 / 房间 / 排位 / 跟读参考句)。按钮、链接、输入框、导航行、中文行不参与;复习答后选项保留它们自己的整行长按。不做「页面上任意英文都能长按」(会把列表行、按钮标题都卷进来)。
D2长按手感按住 450ms 不动(移动 ≤ 8px)→ 选中手指下的那个英文单词(高亮)→ 立刻出操作条(不再等 300ms)。滚动、移动、第二根手指都取消;长按后松手的那一下点击被吞掉(不会跳播、不会翻卡)。只对触摸生效,鼠标照旧拖选 / 双击。
D3系统长按菜单默认保留系统自己的选词(把手、复制 / 分享菜单),只是我们先把词选好、操作条一定出现;这样拖动把手选整句、复制都照常。备选「严格模式」:在可查词文字上压掉系统菜单(安卓上会因此失去长按拖选),不推荐。
D4操作条样式悬浮玻璃胶囊:高 54、圆角 27、白色高光描边 + 柔和阴影 + 28px 模糊;「查词」是实心蓝色胶囊,朗读 / 收藏图标带光晕;位置不变(Tab 栏上方 8px,居中)。
D5抽屉样式悬浮玻璃卡片:左右各 8px、下沿让开 Home 横条、四角圆角 28、36px 模糊;遮罩从 32% 降到 14%(深色 34%),让玻璃后面的页面看得见。内部按钮是半透明「小井」(不再模糊,只有卡片本身一层模糊)。备选:贴底全宽、只有上方圆角。
D6透明度A 6%/38%、B 10%/55%、C 16%/70%(操作条 / 抽屉)。推荐 B:操作条与 Tab 栏同为 10%;抽屉放整段释义,55% 在深色海报上仍能读,A 在亮黄海报上的释义行开始吃力,C 已接近原来的实底。
D7模糊层数操作条和抽屉不会同时出现(打开抽屉时操作条卸载),各算 1 层临时层。大多数页面常驻 3 层(顶栏 / 输入条或 DOCK / Tab 栏),查词时短暂成为第 4 层。跟读库页面已是硬上限 3 层:在那里操作条和抽屉自动改成不模糊的实底玻璃色(与「减少透明度」同样子)。是否接受「临时第 4 层」请确认。
D9操作条盖住 DOCK位置与现在相同(Tab 栏上方 8px),所以有选区时仍会盖住学新词 / 复习的「不认识 / 模糊 / 认识」等 DOCK(现在就是这样,z-40 > z-30);玻璃之后 DOCK 隐约可见。取消选区即恢复。备选:有 DOCK 的页面把操作条抬到 DOCK 之上(要给每个 DOCK 页加一个高度变量,不在本轮)。
D8回退不支持模糊:94% 实心;减少透明度:实心 surface + 发丝线(仍是圆角胶囊 / 卡片);低端机:模糊 12px + 62%(操作条)/ 86%(抽屉)。

本稿只证明「看起来怎样」,手指圆圈与「450 ms」标签只是示意。真机上长按与系统选词的先后、iOS 的「拷贝 / 查询」菜单是否叠出来、模糊质量与深色海报上的可读性都未验证,见计划的真机清单。
