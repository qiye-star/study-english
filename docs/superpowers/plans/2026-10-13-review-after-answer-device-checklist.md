## A. 双击与缩放(最关键)

- [ ] A1 答完一道「看单词选中文」题后,**双击**任意一个选项(手指自然的双击速度):页面**没有**放大(不是缩放状态;`visualViewport.scale` 为 1)。
- [ ] A2 同上,连续双击 5 次(不同选项):每次都不缩放。
- [ ] A3 在**答题前**双击一个选项(它还是按钮):只会答题一次,不会触发查词,页面不缩放。
- [ ] A4 答对后双击正确项、答错后双击你选错的项、双击一个未选的项:三种都能触发(见 B)。
- [ ] A5 慢一点的双击(约 400–500 ms 间隔):不应触发(超出 300 ms 窗口);记录这个手感是否太严——若太严,是否改窗口(`DOUBLE_TAP_MS`)。
- [ ] A6 双击题目单词、结果行、「学习内容」区的文字:行为是 Safari 原本的(不缩放、可能选中单词),没有被我们的逻辑破坏。

## B. 程序化选中与选词操作条

- [ ] B1 双击一个选项后约 0.3 秒内,选区高亮出该选项的**英文单词**(只有单词,不含小字中文),底部出现「查词 · 朗读 · 加入生词本」操作条。
- [ ] B2 iOS 原生的选区句柄 / 放大镜 / 「拷贝、查询」气泡没有盖住操作条或让它闪烁;若出现原生气泡,记录它出现的位置与是否妨碍点击操作条。
- [ ] B3 点「查词」:抽屉里是该单词的词典释义(来源标「词典」);关闭抽屉后选区消失。
- [ ] B4 点「朗读」:第一次点按就发声(iOS 音频解锁在手势里);点「加入生词本」:出现成功反馈。
- [ ] B5 **操作条位置**:复习页底部有「继续」dock;操作条(`bottom` 约 4.5rem + 安全区)**没有盖住「继续」键**,「继续」仍可点;记录两者的相对位置。
- [ ] B6 双击后不点操作条,直接点「继续」:选区与操作条消失,下一题正常。
- [ ] B7 先用手指拖选了页面别处的文字,再双击选项:**不覆盖**你手选的文字(这是 `selectWord` 的规则);记录这个手感是否会让用户困惑。
- [ ] B8 `role="button"` 的 div 里的文字**确实能被程序化选中**(B1 通过即可;若选区为空,这是需要改成别的元素或别的选中方式的信号)。

## D. 答后内容与「中」开关

- [ ] D1 看单词选中文,答错:每个选项显示英文单词;你选的错误项中性(不是红色),带 ×;正确项绿底带 ✓;中文**不直接显示**。
- [ ] D2 点题卡右上角「中」:所有选项下出现小字中文释义,「学习内容」里也出现中文;再点一次收回。点下一题后「中」自动复位。
- [ ] D3 设置里把「释义显示」改成「仅中文」/「中英」再答一题:选项下直接显示中文,没有「中」按钮;「学习内容」里中文可见。改回「仅英文」。
- [ ] D4 遇到一个**没有英文释义**的词(国家 / 城市等):它的选项行回退成中文,不是空的。
- [ ] D5 看中文选单词,答完:每个选项显示英文单词 + 小字「词性. 中文」(如 `v. 说话；谈话`);下方是正确单词的卡片,有英英释义、例句、短语(折叠)、朗读键。
- [ ] D6 「学习内容」区的朗读键:第一次点按发声。短语区(看单词选中文时展开,最多 3 条)可正常展开 / 折叠。
- [ ] D7 例句选词(cloze)题:答完后**和以前完全一样**(选项仍是禁用按钮样式、没有学习内容区、没有提示)。
