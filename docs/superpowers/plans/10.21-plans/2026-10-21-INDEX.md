## 4. 冻结的跨车道接口

- **L1 → 全部**:`app.storage` 暴露 `BlobStore`(`put_file / put_bytes / get_bytes / download_to / open_range / stat / delete / delete_prefix / list`)与 `get_store(app)`;
  键 = 现有相对路径(如 `library/<uid>/<id>/media.mp4`)。其他车道**不得**直接用 `os` / `Path` 读写 `data_dir` 下的持久文件;需要本地文件用 `download_to` 到临时目录。
- **L5 → L4**:`library_segments.speaker` 对 L4 不可见(L4 只读 `text / start_ms / end_ms`,不读 speaker)。
- **L4 ← 事件总线**:L4 只通过 `core/learning_events.py` 订阅;新增事件由各自车道发布:
  - `RealtimeTurnFinished`(L4 在实时通话路径补发,携带 `user_id`、`text` 仅在内存里;文本 `repr=False`)
  - `LibraryItemReady`(L4 在流水线 / 目录导入完成处补发,携带 `item_id` / `catalog_id`);
  - 现有 `MessageSent`、`AssessmentFinished` 沿用;
  - 房间语音转写事件 `RoomVoiceTranscribed(user_id, room_id, text)`:**已纳入**(用户 2026-10-21 按推荐敲定;文本仅内存、`repr=False`;L4 Task 17 解除阻塞,发布点在 `rooms/voice.py` 转写完成处,由 L4 加一行,归属记入 §6)。
  - 事件总线改动(L4 R3/R4:订阅各带总开关、实时与流水线显式传入总线)只由 L4 修改 `core/learning_events.py`。
- **L3 ↔ L4**:互不 import。L4 的例句来源通过 `wordbook` 里的一个小接口 `ExampleProvider`(L4 定义并拥有);L3 不碰 `quiz.py` / `cloze.py`,只改调度与 `grading.py` 的等级映射。
- **L5 → 评分**:只调用已有 `POST /api/speech/assessments`(`source=library`),不改 `speech.py` / `providers/xfyun*`。

- 日志 / 错误 / 审计 / 计量 / URL 中永远没有:单词原文、句子文字、译文、文件名、对象键、用户 id、票据、S3 密钥、预签名 URL。新路由加进 `tests/test_library_privacy.py` 或对应隐私测试清单。

- 不编辑 `enjoy/` 等上游目录;网页需要的适配放 `web/src/shims`。
- 计划里标明**已验证 / 未验证**;没在真机或真实上游跑过的一律写「未验证」,不编数字。
- 提交:一个逻辑改动一个提交,约定式前缀;每个提交后测试保持绿。
