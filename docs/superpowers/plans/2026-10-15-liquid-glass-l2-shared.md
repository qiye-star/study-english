**Goal:** make the shared building blocks wear the v2 skin when `html[data-glass="v2"]`, so ~60 % of the app changes
through them: E1 panels (`.m1`), grouped lists with titles inside the panel (`.grpl .ptitle`), mono icon wells (`.iw`),
pill chips/badges with optional score dot (`.chip`, `.dot`), neutral avatars (`.av`), pill segmented control (`.seg`),
the floating title capsule + large title (`.capsule`, `.lt .large .ltsub`), the T3 floating sheet (`.sheet` = bezel +
plate), the unblurred banner (`.banner`), empty states (`.empty`), the maintenance page, the hold-to-talk plate
(`.hold.plate`), toast classes (`.toast.plate`), and the `LQ_*` vocabulary the area lanes append.

**Architecture:** additive classes (R-LG1) for pure restyles; `useLiquid()` branches (R-LG2) only in `GlassTopBar`,
`PageHeader`, `SectionGroup` and `BottomSheetContent`, whose classic branches stay byte-identical. The `glass` branch of
`BottomSheetContent` (lookup drawer, locked) is not touched.

**Tech stack:** React 18, Tailwind 3 (`liquid:` variant from L0), Radix Dialog, vitest + Testing Library.

## Rulings specific to L2

- **R-L2-1** `IconChip`, `ToneBadge`, `Avatar`, `StatTile` keep their `tone` props and classic colours; under liquid they are
  mono (well + ink). Area lanes never need to change a `tone=` value.
- **R-L2-2** `SectionGroup` (not `bare`) becomes one E1 panel with the 13px title inside (`.grpl .ptitle`); `bare` keeps the
  title on E0 (INDEX D-4). Gaps 16px between panels (`mt-4`).
- **R-L2-3** `PageHeader large` (root-tab pages): large title (30/700, `.large`) + 13px subtitle on E0; the capsule appears
  after 60px of scroll. `back` and `actions` render once — in the large-title row at rest, in the capsule when scrolled
  (no duplicate test ids). Without `large`: capsule always present, glass after 4px; the subtitle is an E0 line under the
  capsule (Rule 4: never on the capsule).
- **R-L2-4** Capsule (`.capsule`): inset `--frame-x`, height 44, pill, title 17/600 centred (`data-glass-title`), leading/actions
  are 44px icon buttons; blur only when scrolled (`mat-chrome-bar`). The large-title row is `-mt-11` so it starts under the
  hidden capsule.
- **R-L2-5** `BottomSheetContent` (default, liquid): floating `mat-sheet` card inset 8px, bottom `max(8px, safe-area − 8px)`,
  radius `sheet-xl` (32), scrim `bg-scrim` (no blur), close button circle. Content sits on the sheet's own plate (R-L0-4).
- **R-L2-6** Banner = E1 panel (`mat-surface`, radius tile, inset `frame`) with a 16px amber icon for warnings; text ink.
  Never blurs (Rev 4).
- **R-L2-7** `ScoreDot` renders a hidden `<i>` in classic (keeps the classic look; tests that snapshot innerHTML must be
  regenerated by the lane that adds a dot).

```tsx
import { cn } from "@renderer/lib/utils";
import { scoreTone } from "./score-tone";

/** 分数点(设计稿 .dot.g / .dot.a):≥85 绿、70–84 琥珀、<70 不画。分数数字本身用墨色(计划 2026-10-15-liquid-glass R-LG10)。 */
export function scoreDotClass(score: number): "bg-green" | "bg-amber" | null {
  const tone = scoreTone(score);
  return tone === "good" ? "bg-green" : tone === "fair" ? "bg-amber" : null;
}

/** 6px 圆点,只在液态皮肤下显示(经典皮肤保持原来的彩色数字)。 */
export function ScoreDot({ score, className }: { score: number; className?: string }) {
  const dot = scoreDotClass(score);
  if (!dot) return null;
  return <i aria-hidden data-score-dot className={cn("hidden size-1.5 flex-none rounded-full liquid:inline-block", dot, className)} />;
}
```
