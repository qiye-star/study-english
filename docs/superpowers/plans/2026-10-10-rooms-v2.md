# 联机练习 v2(Rooms v2)Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在联机练习 v1 之上交付:7 项房间设置与审批加入、与对话页同一手势的房间语音消息(服务端一次转写 + 懒翻译、全房共享、音频永久保存)、不遮挡聊天的停靠式助手面板、房间结束学习小结、文本消息译/朗读、邀请链接与二维码、引用回复与表情回应、正在输入/正在说话,以及配套的管理端(房间设置、存储可见、音频清理工具、用量标签)。

**Architecture:** 服务端保持分层:`app/rooms/` 新增纯模块(`scenarios`、`audio`、`summary`)、数据模块(`voice_store`、`summary_store`)与编排(`voice.VoiceService`);WebSocket 协议 v2 只做加法;语音走 HTTP 上传(`routers/rooms_voice.py`),小结在房间关闭监听里生成(`routers/rooms_summary.py`),两者通过 `app.state.rooms_extensions` 挂到 `RoomsRuntime`(无循环导入)。网页 `features/rooms/` 按车道拆子目录(`create/ voice/ assist/ extras/`),foundation 先把页面拆成插槽并放好有最终接口的桩,各车道只改自己的目录。

**Tech Stack:** FastAPI + SQLAlchemy 2 async + Alembic + pydantic v2 + httpx/respx + pytest-asyncio;`lameenc`(新增,MP3 编码);React 18 + react-router 7 + Tailwind 3 + vitest + Testing Library;`qrcode-generator`(新增,二维码);Playwright(E2E)。

**Spec:** `docs/superpowers/specs/2026-10-10-rooms-v2-design.md`(视觉稿 `docs/superpowers/design/rooms-v2/mockup.html`)。前置:`docs/superpowers/specs/2026-10-09-rank-and-rooms-design.md`、`docs/superpowers/plans/2026-10-09-rank-and-rooms.md`、`docs/superpowers/specs/2026-10-09-admin-console-v2-design.md`、`docs/superpowers/plans/2026-10-09-admin-console-v2.md`(其中的 R-6、G2、D4、E1、E5 与本计划相关)。

```python
import math
import struct


def test_lameenc_encodes_16k_mono_pcm_to_mpeg2_layer3():
    import lameenc

    pcm = b"".join(struct.pack("<h", int(8000 * math.sin(2 * math.pi * 440 * i / 16000))) for i in range(16000))
    enc = lameenc.Encoder()
    enc.set_bit_rate(24)
    enc.set_in_sample_rate(16000)
    enc.set_channels(1)
    enc.set_quality(5)
    mp3 = bytes(enc.encode(pcm)) + bytes(enc.flush())
    assert mp3[0] == 0xFF and mp3[1] & 0xE0 == 0xE0  # MPEG frame sync
    assert 2_000 < len(mp3) < 5_000  # ~3 000 bytes for one second at 24 kbps
```

```python
    async def _attach(self, rows: list[tuple[RoomMessage, str | None]]) -> list[dict]:
        ids = [m.id for m, _ in rows if m.lane == "public"]
        voices: dict[str, RoomVoice] = {}
        reactions: dict[str, list[dict]] = {}
        if ids:
            async with self._sm() as s:
                for chunk in _chunks(ids):
                    voices.update({v.message_id: v for v in (await s.scalars(
                        select(RoomVoice).where(RoomVoice.message_id.in_(chunk)))).all()})
                    for r in (await s.scalars(select(RoomReaction).where(RoomReaction.message_id.in_(chunk))
                                              .order_by(RoomReaction.created_at, RoomReaction.id))).all():
                        reactions.setdefault(r.message_id, []).append(r)
        return [message_out(m, n, voice=voices.get(m.id), reactions=_group(reactions.get(m.id, [])))
                for m, n in rows]

    async def replay_out(self, room_id, user_id, after_seq, limit):
        rows, truncated = await self.replay(room_id, user_id, after_seq, limit)
        return await self._attach(rows), truncated

    async def history_out(self, room_id, user_id, before_seq, limit):
        return await self._attach(await self.history(room_id, user_id, before_seq, limit))

    async def out_one(self, message_id: str) -> dict | None:
        rows = await self._named(self._select().where(RoomMessage.id == message_id))
        return (await self._attach(rows))[0] if rows else None

    async def recent_reactions(self, room_id: str, messages: int = 200) -> list[dict]:
        async with self._sm() as s:
            floor = (await s.scalar(select(Room.last_seq).where(Room.id == room_id)) or 0) - messages
            rows = (await s.scalars(select(RoomReaction).where(RoomReaction.room_id == room_id,
                                                               RoomReaction.seq > floor)
                                    .order_by(RoomReaction.seq, RoomReaction.created_at, RoomReaction.id))).all()
        by_seq: dict[int, list[RoomReaction]] = {}
        for r in rows:
            by_seq.setdefault(r.seq, []).append(r)
        return [{"seq": seq, **g} for seq, items in by_seq.items() for g in _group(items)]

    async def pending_requests(self, room_id: str) -> list[dict]:
        async with self._sm() as s:
            rows = (await s.execute(select(RoomJoinRequest, User.username, Room.name, Room.topic)
                                    .join(User, User.id == RoomJoinRequest.user_id)
                                    .join(Room, Room.id == RoomJoinRequest.room_id)
                                    .where(RoomJoinRequest.room_id == room_id, RoomJoinRequest.status == "pending")
                                    .order_by(RoomJoinRequest.created_at))).all()
        return [request_out(r, n, rn or rt) for r, n, rn, rt in rows]
```

```python
class SummaryStore:
    def __init__(self, sessionmaker): ...
    async def get(self, room_id: str) -> RoomSummary | None
    async def start(self, room_id: str, now: datetime, max_attempts: int) -> bool     # 新建 pending,或 failed 且 attempts<max → pending;attempts+1
    async def finish(self, room_id: str, data: dict, model: str, now: datetime) -> None
    async def fail(self, room_id: str, reason: str, now: datetime) -> None
    async def skip(self, room_id: str, reason: str, now: datetime) -> None
    async def pending(self, limit: int) -> list[str]
    async def lines(self, room_id: str, limit: int) -> list[Line]                     # 公共 text / voice(有文字)/ ai_answer,未隐藏,按 seq 升序取最后 limit 条

@dataclass
class SummaryRunner:
    store: SummaryStore
    complete: Callable[[list[dict], int, float], Awaitable[str]]
    consume: Callable[[str, str, int], Awaitable[bool]]
    refund: Callable[[str, str], Awaitable[None]]
    template: Callable[[str], Awaitable[str | None]]
    room_info: Callable[[str], Awaitable[tuple[str, str, str] | None]]                 # (level, scenario brief, "alice, bob")
    limits: Callable[[], RoomLimits]
    available: Callable[[], bool]                                                   # settings.rooms_summary_available
    model: Callable[[], str]
    clock: Callable[[], datetime]
    async def run(self, room_id: str) -> str                                        # 返回最终状态
```

- `run`:`start` 为 False → 返回现状;`available()` 否 → `skip("disabled")`;`lines` 不满足 `eligible` → `skip("few_messages")`;`consume("room_summary_global", "*", limits.summary_global_daily)` 否 → `skip("quota")`;在 `metering.feature_scope("rooms_summary")`、`bind_user(None)` 下调用 LLM(`assistant.summary_messages`、`SUMMARY_MAX_TOKENS`、`SUMMARY_TEMPERATURE`);上游异常 → 退还额度,`fail("upstream")`;`SummaryFormatError` → `fail("format")`(不退还);成功 → `finish`。

## 验收标准

1. `ROOMS_ENABLED=false`:所有新端点 404(config 除外),网页不显示联机入口;`ROOMS_ENABLED=true` 且两个子开关关:创建表单 7 项中"允许语音"不显示,其余 v2 功能可用,零新增上游调用。
2. 创建房间的 7 项设置按 spec §3.1 的默认值与约束工作;房主改设置产生一条 `settings` 系统消息;人数上限不能低于当前成员数。
3. 审批房间:房间号加入得到 202 与"等待房主同意";房主在线收到实时请求,同意后请求者自动进房;10 分钟过期;被拒 30 分钟冷却;邀请链接直接进入(锁定、已满、被移出、已结束仍拒绝);重置后旧链接 404;token 不出现在任何日志。
4. 语音:与对话页同一手势;松手发送 → 所有在线成员收到语音消息与随后的 `voice_update`;服务端每条语音最多一次成功转写、最多一次成功翻译,与收听人数无关(测试断言上游调用次数);发送者可重试失败的转写,其他人不能;非成员、被移出者、隐藏消息拿不到音频;音频以 MP3(或配置的 WAV)永久保存。
5. 自动转文字开关默认关;开启后收到的语音自动显示转写与译文;关闭时手动「转文字」「翻译」可用。
6. 助手停靠面板不遮挡聊天(E2E 断言),高度不超过视口 40%,键盘弹出收成一行,可拖动三档、可收起与关闭;入口为圆形主色按钮,新建议时有琥珀未读点;建议卡「发送」直发群聊并带「助手润色」,「改一改」填回输入框。
7. 房间结束后(满足条件时)生成一次学习小结;概述与生词全员可见,"可以说得更好"只给本人;生词一键进词汇本;每日上限生效;失败可重试 1 次。
8. 文本消息「译」「朗读」与对话页行为一致;6 个表情回应与引用回复实时同步,隐藏被引用消息后引用摘要清空;正在输入/正在说话只发给他人、6 秒消失。
9. 管理端:房间设置可见可改(带原因、审计);语音时间线可播放(审计);存储卡显示房间语音字节与增长;`room_audio` 清理工具需扫描 + 原因 + 二次验证,清理后转写保留;用量页出现「联机语音」「联机小结」。
10. `tests/test_architecture.py`、`web/src/architecture.test.ts`、`tests/test_settings_registry.py`、`tests/test_migrations.py`、契约测试(v1 + 3 个 v2 样例)全部绿色;v1 房间测试无删减地通过(只有 spec 明确改变的断言被更新)。
