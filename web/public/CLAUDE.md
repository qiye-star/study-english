# web/public/

Static files copied as-is to `dist/`.

## What lives here
- `sw.js` — minimal service worker: cache-first for hashed `/assets/*` and versioned `/vad/*` only (max 80 entries); API, audio, `index.html` go to network.
- `manifest.webmanifest`, `icons/` — PWA metadata and icons (incl. maskable, apple-touch).
- `vad/` — generated by `scripts/copy-vad-assets.mjs`; git-ignored, do not commit.

## Test
- `cd web && yarn test` (`src/pwa/sw.test.ts` covers `sw.js`).

## Pitfalls
- Changing caching rules: bump `CACHE` in `sw.js` so old caches are dropped.
- Never cache API responses, recordings or anything user-specific.
