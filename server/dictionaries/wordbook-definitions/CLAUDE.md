# server/dictionaries/wordbook-definitions/

English definitions shown under the Chinese meaning on wordbook cards (spec 2026-10-12-wordbook-definitions). Read at
runtime by `app/wordbook/definitions.py`; a missing or broken file silently means "no English definitions".

## What lives here
- `definitions.jsonl` – GENERATED by `scripts/wordbook_definitions.py build`: one line per word `{"word", "defs": [{"pos", "text", "src"}]}`,
  sorted by word, UTF-8, LF, at most 2 defs per part of speech. `pos` is `n v a r prep pron conj art num aux int`; `src` is `oewn | hand | llm`.
- `function-words.jsonl` – HAND-WRITTEN (`src: "hand"`): the most frequent function words. The only file here you edit by hand.
- `definitions-llm.jsonl` – written only by `llm-fill` (`src: "llm"`); raw model output (620 gap words), merged (and style-normalised) by `build`; rewritten only by `llm-fill`.
- `forms.txt` – GENERATED by `scripts/wordbook_definitions.py forms`: `form<TAB>lemma`, sorted, LF (21,074 rows, 361,197 bytes); inflected forms of word-book headwords from ECDICT exchange (rules R-L8: skips forms that are headwords themselves; commonest lemma wins); read by `app/wordbook/forms.py`
- `missing.txt` – GENERATED gap list `word<TAB>pos,pos<TAB>category<TAB>frq` (function / abbr / proper / compound / pos_mismatch / other).
- `SOURCE.json` – GENERATED manifest: input names, versions, sha256, rules, file checksums, counts.
- `LICENSE-OEWN`, `LICENSE-ECDICT` – licence texts (also in the root `NOTICE`).

## Rules
- Never edit generated files by hand; change the script or the inputs and rebuild (`server/scripts/CLAUDE.md`). Commit a rebuild alone:
  `chore(server): update wordbook English definitions (<reason>)`.
- `build` carries the `forms` manifest entry over; regenerate `forms.txt` (and commit it) alone.
- `.gitattributes` marks `*.jsonl` and `missing.txt` as `binary` (checksums stay stable on Windows).
- Build inputs (OEWN zip, ECDICT zip) are NOT in the repo; they are checked by sha256 (`wordbook_definitions.py verify`).
- Function words (`in`, `it`, `a` ...) must never come from WordNet: `build` skips WordNet for `prep pron conj art num aux int`.
- A word with a hand entry is hand-only: `build` adds no WordNet line for ANY of its POS (R-DS17; `in` is not indium). Other words: WordNet, then llm.
- `src: "llm"` lines are normalised by `build` (R-DS19: whitespace collapsed, one trailing period dropped, first letter lowercased unless acronym / `I` / the text holds another capitalised word; a leading A/An/The is always lowercased); `definitions-llm.jsonl` itself stays raw model output. No POS filter for llm lines (R-DS20: none is outside the book POS set; wrong lines come from mis-typed book POS).
- `build` drops WordNet senses whose gloss opens with an explicit usage label (`(slang)`, `(British informal)`, `slang for ...`) while the POS keeps another sense (R-DS18; never the only sense).
- `function-words.jsonl`: sorted by word, LF/UTF-8, one entry per (word, pos), closed-class POS only, each text <= 12 words,
  original wording (no copied dictionary text). The POS must be one the word book gives the word (strict build).
- The runtime finds this folder next to the word-book folder (`<WORDBOOK_DATA_DIR>/../wordbook-definitions/`). If you point
  `WORDBOOK_DATA_DIR` elsewhere, put this folder beside it, otherwise cards silently have no English definitions.
- Copied into the image by `server/Dockerfile` (`/app/dictionaries`); whitelisted by `!server/dictionaries` in `Dockerfile.dockerignore`.

## Test
`uv run pytest -q tests/test_wordbook_function_words.py tests/test_wordbook_definitions_data.py tests/test_wordbook_definitions_build.py tests/test_wordbook_forms_data.py tests/test_wordbook_forms_build.py`
(hand file + licences; checksums/schema/sorting/wiring of the committed data; the builder with fixtures). Rebuild:
`uv run python scripts/wordbook_definitions.py verify --sources <dir>` then `build --sources <dir>` then `check`.

## Measured (build 2026-10-12, script_version 2, with the merged LLM file)
14,615 keys, 14,480 words with a definition (13,916 with OEWN, 620 with llm of which 459 llm-only), 29,626 defs; pairs oewn 17,719 / hand 118 / llm 683;
135 gap rows (function 0, proper 105, abbr 14, compound 13, pos_mismatch 1, other 2); `definitions.jsonl` 2,697,348 bytes; `missing.txt` 2,707 bytes.
Known weak picks (accepted by design: POS follows the book): `grass` n2 is "a police informer"; llm lines for book-mistyped POS (`anybody` prep, `another` prep, `all` prep, `dare` aux; R-DS20).
